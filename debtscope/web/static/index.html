先连接模型

模型用于废弃代码 AI 精判、框架隐式入口识别，以及把自然语言变成自定义指标。 Key 仅保存在本机 ~/.debtscope/config.json（权限 600），代码与 Key 都不会上传到第三方。

内置 16 套预设：豆包方舟（默认）/ DeepSeek / 通义千问 / 智谱 GLM / Kimi / 混元 / 千帆 / MiniMax / 小米 MiMo / 硅基流动 / OpenAI / Gemini / Grok / Mistral / 本地 Ollama / 任意 OpenAI 兼容端点（内网网关、vLLM）； 也可设置环境变量 DEBTSCOPE_API_BASE / DEBTSCOPE_API_KEY / DEBTSCOPE_MODEL 后刷新。
